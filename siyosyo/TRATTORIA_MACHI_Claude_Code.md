# トラットリア まちの灯｜Webサイト制作・実装仕様書

> **架空店舗の営業用ポートフォリオ。** 店舗、人物、価格、提供内容はすべて創作。実店舗の公式サイトと誤認されないよう全ページにデモ表記を置く。住所・電話番号・SNS ID・口コミを架空で補わない。店名の重複・商標は未調査。

## 0. Claude Codeへの実装指示
本書をベースに、家族経営の大衆向けイタリアンの魅力を伝えるレスポンシブサイトを作成する。既存の飲食店デモをテンプレートとして使い回さず、手書きメニュー・温かい家族経営・日常のごちそうを軸に設計する。Next.js App Router + TypeScript + Tailwind CSSを推奨。主要コンテンツはデータとして分離し、ビルド・型チェックを実施する。予約フォームは非送信のデモであり、個人情報を入力させない。

### ブランドコピー
**「いつもの街に、ちょっといいイタリアン。」**

気取らない空間、たっぷりのパスタ、焼きたてのピッツァ。家族と、友人と、仕事帰りに。特別な記念日だけでなく、ふと思い立った平日の夜にも立ち寄れる、小さなトラットリア。

### ストーリー（すべて架空）
料理人の夫と、接客を担当する妻が営む地域密着のイタリアン。夫は東京のカジュアルイタリアンで経験を積んだ後、会津に戻って店を開いた。地元の旬野菜を時期に合わせて取り入れ、ソースやドレッシングを店内で仕込む。子ども連れにも歓迎の雰囲気を大切にしている。

※「地元農家と契約」「イタリアで修業」「石窯焼き」など、設定にない強い事実主張を追加しない。ピッツァはオーブン焼き。

## 8. 機能要件
### メニュー切替
- Lunch / Pasta / Pizza / Antipasti / Dolce & Drink。
- 商品名・説明・価格をデータから描画。
- ランチ提供時間を目立つ場所に表示。
- 税込表記を明示。

### 2名セット組み合わせシミュレーター
- パスタ1品、ピッツァ1品、ソフトドリンク2杯を選択。
- 選択内容と固定セット価格¥4,200を表示。
- 「これは注文・予約ではありません」と明記。
- 送信処理、予約完了メッセージ、個人情報入力は設けない。

### 予約案内
- ディナーは電話予約想定。ただしデモに電話番号はないため、「実店舗化時に電話番号・予約導線を設定予定」と表示。
- 予約フォームを実装する場合はUI見本にとどめ、入力欄に個人情報を要求しない。代わりに「予約機能デモ」説明モーダルで十分。

### お知らせ
- 営業日の変更例を表示するなら **架空のサンプル** と明示。
- 例：`【サンプル】季節のおすすめメニューを準備中です`。
- CMSは不要。将来差し替えやすいようデータ定義を分離。

## 9. 技術・運用品質
- Next.js + TypeScript + Tailwind CSS推奨。外部APIキー不要。
- 店舗情報・メニューは`data/site.ts`、`data/menu.ts`に分割。
- 375px/768px/1280pxで表示検証。モバイル時は料理写真と価格を優先。
- SEO：title `トラットリア まちの灯 | 架空イタリアン店舗 デモサイト`。meta descriptionもデモ明記。
- 画像最適化、alt、正しい見出し階層、キーボード操作、適正コントラスト。
- `prefers-reduced-motion`に対応。
- 実在しないレビューの捏造、架空Googleマップのピン、偽Instagramリンク、注文・予約の完了演出は禁止。
