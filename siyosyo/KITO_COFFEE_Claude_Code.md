## 1. Claude Codeへの依頼

この文書を唯一の店舗情報ソースとして、日本語の高品質なレスポンシブWebサイトを実装してください。制作目的は小規模飲食店への営業用ポートフォリオです。一般的なテンプレートの流用感を排し、雑誌のような編集的レイアウト、上質な写真、繊細なタイポグラフィで「ブランド体験」を訴求してください。見た目だけでなく、表示速度・操作性・アクセシビリティ・検索エンジン向けの情報構造を満たしてください。

**既存リポジトリがある場合は先に技術構成を確認し、破壊的変更を避けること。** 新規作成なら Next.js (App Router) + TypeScript + Tailwind CSS を標準とする。外部API・認証・DB・CMSは初期段階では不要。画像は利用権限を確認したローカル素材を置く構成にし、素材未準備時は色付きの上品なプレースホルダーを配置する。画像がない場合もレイアウトが崩れないこと。必要な画像を勝手にスクレイピングしない。

## 5. ビジュアルデザイン

- テーマ: `Minimal / Calm / Editorial`
- 背景 `#F5F2EA`／文字 `#272924`／アクセント `#8A7158`／サブ背景 `#E7E1D6`
- フォント: 日本語は `Noto Sans JP`、英語見出しは上品なセリフ体（例 `Cormorant Garamond`。利用できない場合はシステムセリフ）。Google Fontsを使う場合はパフォーマンスとライセンスに配慮。
- 見出しは大きく、本文は14–17px程度。行間はゆったり。長文は幅を絞る。
- 写真は自然光、陶器、コーヒーの液面、木材の質感。暖色すぎるフィルターや過度な影を避ける。
- サイト全体に十分な余白と写真のサイズ差を使う。カードの羅列は禁止。
- PCヒーロー: 画面約80–90vh、全面写真＋読みやすいオーバーレイ、左寄せ文字。
- PC本文: Aboutを写真×テキストの非対称2カラム、Coffee storyに写真を大胆に使用、Menuは整然としたテキストリスト。
- モバイル: 高さを抑えたヒーロー、メニューを読みやすくし、CTAを押しやすくする。
- 交互に流れるスクロール演出や無意味なパララックスは使わない。`prefers-reduced-motion`対応。

## 8. 技術・アクセシビリティ・SEO

- 静的サイトとしてビルドできること。ストア、予約、問い合わせ、レビュー収集は実装しない。
- SEO: `title = KITO COFFEE | 架空カフェ デモサイト`、適切なmeta description、OG画像は自作素材を使用。
- デモの公開時は `noindex, nofollow` を設定し、実在する店舗の検索結果を汚染しない。
- 構造化データの `LocalBusiness` は使わない（架空店舗を実在の場所として登録しない）。
- セマンティックHTML、唯一のh1、適切なh2/h3、画像alt、キーボードナビゲーション、フォーカスリング。
- コントラストを確保、縮小表示時に水平スクロールしない、44pxを目安にタップ領域確保。
- `<Image>`などの最適化、サイズ指定、lazy loading、CLS防止。
- 初期ロード時の画像とフォントを最適化、不要なJSを削る。
- HTML内の表記は自然な日本語。プレースホルダーのダミー文字列や不自然な英語を残さない。
