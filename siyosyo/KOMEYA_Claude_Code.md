## 1. Claude Codeへの依頼

この資料をもとに、KITO COFFEEとは視覚・UI・構成がはっきり異なる、昔ながらの定食屋のWebサイトを制作してください。ターゲットは地元住民・会社員・子連れ家族・観光客。**サイトの目的は、メニューと価格をすぐ探せること、昼夜の営業時間がひと目でわかること、持ち帰り情報を把握できること。** 写真や装飾よりも使いやすさを優先。ただし懐かしく温かいビジュアル品質を保つ。

既存リポジトリがある場合は技術構成を確認。新規なら Next.js App Router + TypeScript + Tailwind CSS。初期段階では外部API・DB・CMS・購入機能不要。画像は利用許諾のあるものだけ。未提供時は雰囲気あるプレースホルダーを使い、画像の無断収集は禁止。

## 5. ブランド／デザイン方向

- キーワード: `Nostalgic / Warm / Friendly / Practical`
- 背景 `#F7F0DF`（生成り）、メイン `#A34331`（朱色）、サブ `#435442`（深緑）、本文 `#382E25`（焦茶）。
- 太めで親しみやすい日本語書体（例 Noto Sans JPのBold）。英字装飾は控えめ。
- ヒーローは唐揚げ定食の大きな料理写真＋左に力強いコピー。価格や営業時間へのリンクを見せる。
- 余白はKITOより少し詰め、情報が素早く見つかる構成にする。
- 赤系の小見出し、印章・のれん・罫線をモチーフにした控えめな和のあしらい。レトロを過剰に演出しない。
- メニューはカテゴリー別にし、料理名・価格・説明が視認できる。画像は看板商品2点を大きく見せ、それ以外は一覧として軽快にする。
- グローバルナビは `こめやについて`、`お品書き`、`お持ち帰り`、`店舗案内`。スマホはアンカーリンクと必要情報がすぐ見つかるメニュー。
- 演出よりも速度と使いやすさを優先。ホバー依存禁止。

## 6. ページ構成（1ページ完結）

1. **Header**：お食事処 こめや／メニュー／店舗案内へのナビ
2. **Hero**：看板の唐揚げ定食、キャッチコピー、メニューCTA、昼夜の営業案内
3. **こめやについて**：お米・家庭料理・開業以来の想い
4. **名物料理**：唐揚げ定食と会津ソースカツ丼（写真・価格・説明）
5. **お品書き**：定食、丼、単品、子ども向け。税込明記
6. **日替わりについて**：「内容は店頭でご案内」程度の案内のみ。実際の更新機構は不要
7. **お持ち帰り**：弁当メニューと価格。購入ボタンを置かない
8. **店舗案内**：営業時間、L.O.、定休日、座席、駐車場、決済、所在地の地域名のみ
9. **Footer**：架空店舗の免責表示

## 8. 実装要件

- モバイルファースト。画面幅320px以上で横スクロールなし。
- メニューはデータ配列から生成して、価格・カテゴリを後から編集しやすくする。
- 注文・電話・予約・外部SNSボタンは実際に存在する連絡先がないため非表示。
- 架空の地図ピンを実在する建物に立てない。所在地は会津若松市の地域名のみ。
- 販売中や本日営業中などのリアルタイム状態を偽装しない。
- SEO: `お食事処 こめや | 架空食堂 デモサイト`。robotsに `noindex,nofollow`、構造化LocalBusinessデータは作成しない。
- 一つのh1、階層化された見出し、適切なalt、キーボード操作とフォーカス可視化。
- 色のコントラスト、タッチ領域、`prefers-reduced-motion`、画像レイアウトシフト対策。
- 型チェック、Lint、ビルドを実行してエラーを修正。

## 9. 完了条件

- ヘッダーからメニュー・営業時間・店舗案内にアクセス可能
- 全メニュー名・価格・セット条件・L.O.が設定と一致

- 実在の連絡先・架空のレビュー・虚偽のSNSリンクがない
- デモ免責が全画面で確認可能
- 320px〜1440pxでレスポンシブ検証
