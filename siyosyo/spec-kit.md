# machi studio. 公式Webサイト制作仕様書

**Version:** 1.0  
**Project:** machi studio. — Brand Website  
**目的:** Instagram営業に使用するWeb制作サービスの公式プロフィールサイト  
**制作方法:** Claude Codeによる実装  
**優先デバイス:** スマートフォン

---

# 1. プロジェクト概要

## 1.1 サービス名

**machi studio.（マチスタジオ）**

キャッチコピー：

**小さなお店に、ちょうどいいWebを。**

サブコピー：

お店の魅力が、まっすぐ伝わる場所を。

※ブランド名は仮決定。正式公開前に名称・商標・ドメイン・Instagram IDの重複確認を行う。

## 1.2 事業概要

machi studio. は、飲食店・カフェ・ベーカリー・個人商店など、小規模な地域店舗を対象としたWebサイト制作・運用サービス。

大規模な制作会社とは異なり、小規模な店舗に必要な機能を整理し、デザイン性と使いやすさを両立したWebサイトを提供する。

主なサービス：

- Webサイトの企画・デザイン
- Webサイト制作
- スマートフォン対応
- 店舗情報・メニュー・アクセス情報の整理
- 公開・ドメイン設定支援
- 公開後の保守・軽微な更新

制作にはClaude CodeなどのAI開発ツールを活用するが、AIによる自動生成をブランドの売り文句にはしない。

最終的な品質管理・顧客対応は運営者本人が行う。

## 1.3 運営形態

- 現在は個人で活動
- 現在の活動拠点：福島県会津若松市
- 将来的な活動拠点：長野県安曇野市
- 遠方の既存顧客にもオンラインで対応する方針

株式会社や大規模な制作会社であると誤認させる表現は使用しない。

「チーム」「多数の専門スタッフ」「豊富な納品実績」など、実態と異なる表現は禁止。

## 1.4 Webサイトの目的

第一目的：

Instagramの営業DMを受け取った店舗経営者が、サービス内容と運営者を理解し、安心して問い合わせできること。

第二目的：

今後作成する飲食店向けサンプルサイトや実際の制作実績を掲載し、ポートフォリオとして成長させること。

第三目的：

会津若松から安曇野に拠点を移しても、長期的に使い続けられるWebブランドを構築すること。

## メインターゲット

- 飲食店の経営者
- ベーカリーの経営者
- 地元の小規模商店

## 訪問者に与える印象

- 相談しやすそう

- 過度に営業的ではない

# 3. デザインコンセプト

## 3.1 基本方針

コンセプト：

**Quiet, thoughtful, and local.**

静かで、誠実で、地域に寄り添うデザイン。

小規模なデザインスタジオのポートフォリオサイトのような洗練されたビジュアルを目指す。

一般的なテンプレートサイトや派手な営業用ランディングページにはしない。

## 3.2 カラーパレット

| 用途 | 色 | HEX |
|---|---|---|
| メインカラー | Forest Green | `#243D35` |
| ベース背景 | Warm Ivory | `#F2F0E9` |
| アクセント | Sage Green | `#A8B2A3` |
| 白系背景 | Soft White | `#FAF9F5` |
| 本文サブカラー | Muted Green Gray | `#63736B` |
| 区切り線 | Warm Gray | `#D8D9D0` |

メインカラーは深緑。

温かみのあるアイボリーを背景として使用し、全体的に落ち着いたトーンを作る。

## 3.3 タイポグラフィ

日本語：

- Noto Sans JP
- または同等の可読性の高い日本語フォント

英語：

- Manrope
- または同等のモダンなサンセリフ

必要に応じて、英語見出しの一部に上品なセリフ体を取り入れてよい。

ただし、可読性を犠牲にしない。

フォントウェイトは400〜600を中心に構成。

巨大な太字見出しを多用しない。

## 3.4 レイアウト

- 余白を大きく取る
- グリッド構成を意識する
- 情報量を抑える
- セクション間に明確なリズムを作る
- 角丸は小さめ
- 影は極力使用しない
- 細い区切り線を活用
- コンテンツの最大幅は約1100〜1200px
- スマートフォンで自然な1カラムにする

## 3.5 アニメーション

アニメーションは控えめにする。

許可する例：

- スクロール時の軽いフェードイン
- ボタンの色変化
- リンクのホバー表現
- ナビゲーションの穏やかな開閉

禁止：

- 大きなパララックス演出
- 常時動き続ける装飾
- 過剰なスクロールアニメーション
- 読み込みを遅くする演出

`prefers-reduced-motion` に対応すること。

# 6. 技術仕様

## 6.1 推奨技術

- Astro
- TypeScript
- CSS / Tailwind CSS
- Git / GitHub
- Cloudflare Pages

基本的に静的サイトとして構築する。

初期段階ではデータベース不要。

認証機能不要。

サーバーサイドAPIも原則不要。

## 6.2 Astro採用理由

- 静的サイトの構築に適している
- JavaScriptを必要最小限に抑えやすい
- SEOを考慮しやすい
- コンポーネント単位で拡張できる
- 長期的な保守が比較的容易

Reactなどを使用する場合も、必要性を明確にすること。

単純な表示だけのために過剰なライブラリを導入しない。

**End of Specification — machi studio. v1.0**



添付の仕様書に基づいて、machi studio. の公式Webサイトを制作してください。

特にデザインの完成度を重視します。

一般的なAI生成サイトによくある、画一的なカード配置、大きすぎる角丸、過剰なグラデーション、絵文字や装飾アイコンの多用は避けてください。
