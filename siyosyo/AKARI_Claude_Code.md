# 炭火と酒 灯｜Webサイト制作・実装仕様書

> **架空店舗・ポートフォリオ用デモ**。店舗・メニュー・料金・人物・運営情報はすべて創作です。実在する飲食店・酒蔵の公式サイトと誤認される表現を避けてください。

## 0. 制作目的とコンセプト
- 店舗名：**炭火と酒 灯（あかり）** ／英字表記：**SUMIBI TO SAKE AKARI**
- 業態：備長炭の炭火料理と会津の地酒を楽しむ小規模な和モダン居酒屋。
- 想定客層：30〜60代、会食客、カップル、旅行者、少人数の宴席。
- 目標：料理の魅力、落ち着いた空間、コース内容、予約方法を短時間で把握できること。
- ダークトーンの高品質な**1ページWebサイト**。焼き上がり案内中心のベーカリーとは明確に異なる情報設計。

## 2. ブランドストーリー／コンテンツ
炭火を囲む、静かな夜。会津若松の路地裏にある「灯」は、備長炭で焼く旬の食材と、料理に寄り添う日本酒が主役の小料理店です。素材に合わせて火入れを変え、季節の味わいを一皿ずつ丁寧に仕立てます。カウンター越しに伝わる炭火の音、ほのかに漂う香りを楽しむ大人の時間をご提案します。

### 店主設定（架空）
40代の料理人。和食店で修業後、地元・会津若松で独立。炭火の火入れと日本酒の組み合わせを研究し、季節ごとに献立を更新する。人物写真は不要。

## 5. 予約導線（動作するデモ、実送信なし）
- グローバルHeaderに目立つ `ご予約について` アンカーを設置。
- #reservation セクションに予約の想定フロー・営業時間・人数・コース条件を記載。
- **本番と誤認させる予約送信フォームは設置しない。** 代わりに `予約画面のデモを見る` ボタンから、非送信のプレビューダイアログを開く。
- ダイアログ内のUI（デモ限定）：来店希望日、時間帯（17:30 / 18:00 / 19:00 / 20:00）、人数（2–6名）、コース選択（席のみ / 季節コース / おまかせコース）。
- コース注文の際の2名以上条件をバリデーション。過去日・日曜は選択不可。営業時間外を設定しない。
- `内容を確認` により入力値を画面上に表示。ただし保存・送信・通知・空席確認・予約確定は行わない。
- 目立つ注記：`こちらはポートフォリオ用の操作デモです。予約は送信・確定されません。`
- 確認画面には `入力内容を修正` と `閉じる` を設置。**予約完了**という表記を使わない。
- フォームの氏名・電話・メールなど個人情報フィールドは不要。

## 6. デザインシステム
- デザイントーン：`Cinematic / Dark / Japanese Modern / Refined`。
- 背景 `#171613`、セクション `#211E19`、文字 `#E8DFCD`、アクセント `#BA8850`、補助 `#493A2B`。
- 英字：トラッキング広めの細身のセリフ。日本語：明朝体の大見出し、可読性の高いゴシック体本文。
- Hero：炭火の炎・焼き台・煙のディテールを大きく。読みやすい暗幕グラデーション。無音ループ映像がなければ静止画を採用。
- 余白を大胆に取る。スプリットレイアウト、縦書きの短い見出し、細い金茶色のライン。
- アニメーションは控えめにし、`prefers-reduced-motion` 対応。スクロール妨害、過剰なパララックスは不要。
- 写真は低照度でも料理の色と質感が伝わるもの。暗すぎる写真やコントラスト不足を避ける。
- **KITO COFFEE / こめや / 麦と日々と同じカードUIをコピーしない**。この店舗独自の編集的レイアウトにする。

## 9. 技術・品質要件
- Next.js App Router、TypeScript、Tailwind CSS推奨。既存のプロジェクト設定は尊重する。
- メニュー・コース・営業時間を `src/data/akari.ts` 等に集約。
- ダイアログはフォーカストラップ、Esc閉じ、適切なaria属性、キーボード操作対応。
- 日付計算はAsia/Tokyoを基準にし、端末タイムゾーンとの差で予約可能日がずれないようにする。
- 日曜は架空の定休日として選択不可。日付選択で実際の空席情報を示唆しない。
- SEO・OG画像・画像最適化・適切なalt・セマンティックHTML・WCAG AA・モバイル最適化。
- デモサイトには `noindex` を推奨。架空情報で実在のLocalBusiness構造化データを生成しない。
- 外部予約サービス・電話発信・送信API・決済などを架空のまま接続しない。

## 10. 検収項目
- 料理・ドリンクとコースの税込価格が正しく表示される。
- メニューカテゴリ切替と予約プレビューダイアログが動作する。
- コース人数条件、過去日、日曜の入力制御が動く。
- 「予約確定」に相当する誤認表現がない。
- モバイル幅320px〜、タブレット、PCで破綻しない。
- 日本語の折り返しが自然で、本文・写真ともに十分な可読性がある。
- 型チェック、lint、ビルドに成功し、ランタイムエラーがない。
- READMEにデータ編集箇所、画像クレジット、デモ注記、起動方法を書く。
