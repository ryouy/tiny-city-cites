# HAIR SALON niwa — Claude Code 制作仕様書

> **架空店舗のポートフォリオ用デモサイト**。実在店舗ではありません。2026年10月13日作成。店名・人物・料金・店舗情報は創作です。公開サイトには架空店舗である旨を目立つ位置とフッターに表示すること。

## 1. 制作目的
小規模・完全予約制の美容室へ営業提案するための完成度の高いサロンサイトを制作する。清潔感、安心感、スタイリストの人柄、料金の透明性を重視。ポートフォリオでは、サロン特有の「施術事例」「担当者」「メニュー料金」「予約導線」のUIを実装する。

### 架空のブランドストーリー
店名「niwa」には、小さな庭のように自分のペースで過ごせる場所という思いを込めた。大きなサロンのにぎやかさが苦手な人にも、相談しながら髪型を決めたい人にも、肩肘張らずに通える空間。派手な流行を追うより、毎朝扱いやすい髪と、自然体の似合うスタイルを提案する。

### ターゲット
- 25〜50代、落ち着いた美容室を好む顧客
- 初来店で料金・所要時間・スタッフの雰囲気を確認したい人
- 子育てや仕事で忙しく、セットしやすい髪型を希望する人
- Instagramのスタイル写真からサロンを探す人

## 3. Web掲載用文章

### About
- 見出し：`背伸びをしない、自分らしいきれい。`
- 本文：`髪質も、暮らし方も、似合うスタイルも一人ひとり違うから。niwaではカウンセリングの時間を大切にし、日々のお手入れまで見据えたヘアデザインをご提案します。落ち着いた空間で、どうぞゆっくりお過ごしください。`

### Concept 3つの約束
1. `丁寧なカウンセリング` — 悩みや好み、普段のセット方法までじっくり伺います。
2. `毎日に馴染むスタイル` — サロン帰りだけでなく、翌朝も扱いやすい髪へ。
3. `静かに過ごせる空間` — 2席だけのプライベートな空間で、自分の時間を。

### First Visit
- 見出し：`はじめての方へ`
- 文：`ご希望の髪型が決まっていなくても大丈夫です。髪のお悩みや普段のライフスタイルを伺いながら、一緒にスタイルを考えていきます。`

## 7. 情報設計・ページ
- `/` Home：Hero → Concept → Featured Styles → Menu preview → Stylists → First Visit → Access → Footer
- `/styles` Styles：フィルター `All / Short / Bob / Medium / Long / Men's`、各スタイルの詳細モーダル（画像・説明・関連メニュー）
- `/menu` Menu：`Cut / Color / Perm / Care / Set` のカテゴリ切替、料金表、所要時間、注意事項
- `/staff` Staff：2人のプロフィール、得意ジャンル、メッセージ（架空人物表記）
- `/first-visit` First Visit：来店フロー、FAQ、カウンセリングの説明
- `/reserve` Reservation Demo：スタッフ、施術、日時、氏名などの入力UI。**架空の選択肢によるデモのみで、実送信は不可**。
- `/access` Access：営業時間、定休日、駐車場、所在エリア。住所・電話・地図の架空ピンは作らない。

### 予約導線
CTAは `予約デモを体験` にし、ユーザーが実予約と誤認しないようにする。実在の外部予約システムと接続しない。

## 11. FAQ（掲載原稿）
**Q. 髪型が決まっていなくても大丈夫ですか？**
A. もちろんです。髪質や普段のスタイリングについて伺いながら、一緒に考えていきます。

**Q. 所要時間はどのくらいですか？**
A. カットは約60分、カットとカラーは約150分が目安です。施術内容や髪の状態により前後します。

**Q. 子どもと一緒に来店できますか？**
A. デモ設定では同伴相談可とします。実際の営業案内として使用しないでください。

**Q. 当日予約はできますか？**
A. デモ設定では空き枠に応じて対応とします。ただし実予約を受け付ける機能はありません。

## 12. 技術・品質要件
- Next.js App Router / TypeScript / Tailwind CSSを推奨。既存技術基盤がある場合はそちらに従う。
- `src/data/services.ts`、`src/data/styles.ts`、`src/data/staff.ts` にデータを分離する。
- コンポーネント例：`Hero`, `StyleFilter`, `StyleCard`, `StyleModal`, `MenuCategoryTabs`, `StylistCard`, `BookingDemoWizard`, `FAQAccordion`, `DemoNotice`。
- レスポンシブ：幅360px / 768px / 1024px / 1440pxで表示検証。
- アクセシビリティ：画像alt、適切な見出し、操作可能要素のフォーカスリング、コントラスト、キーボード操作、reduced-motion対応。
- パフォーマンス：画像最適化、LCP改善、必要なアセットだけ先読み。
- SEO：架空店舗のため`noindex,nofollow`。実在事業を装うLocalBusiness構造化データ、架空住所、SNS、地図レビューは作成しない。
- 本番認証、実決済、個人情報の外部送信は禁止。予約フォームはブラウザ内のデモ動作のみ。
- ヘッダー付近・フッター・予約UIには `PORTFOLIO DEMO｜架空店舗の制作事例です` と表示。

## 13. 受け入れ基準
- すべてのメニュー・価格・所要時間が仕様と一致
- ギャラリーのカテゴリ・モーダルが操作できる
- 予約ウィザードが動くが実際の予約は成立しない
- スタッフ名とプロフィールが創作である旨を明示
- モバイルでも文字とボタンが操作しやすい
- ブラウザのコンソールにエラーなし、lint/build成功
- 実在の電話番号・住所・口コミ・SNSを捏造していない
- ほかのポートフォリオ店舗と異なる美容室専用のデザインに仕上がっている
