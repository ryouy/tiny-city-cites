# 麦と日々｜Webサイト制作・実装仕様書

> **架空店舗・ポートフォリオ用デモ**。掲載する所在地・商品・営業条件・ストーリーは架空の設定です。実在店舗の公式ページを装わないこと。

## 0. 制作目的と成功基準
- 店舗名：**麦と日々（むぎとひび）**／英字表記：**MUGI TO HIBI**
- 業態：国産小麦と自家製天然酵母を中心とした、夫婦経営の小規模ベーカリー。テイクアウト中心。
- ユーザー：近隣住民、子育て世帯、パン好き、週末の観光客。
- 訪問者が最初の10秒で「何のお店か」「いつ開いているか」「おすすめのパン」「売り切れ・焼き上がりの見方」を理解できること。
- 実装は高品質な**スマホファーストの1ページサイト**。商品詳細、営業カレンダー、焼き上がり案内はセクションまたはモーダルで表現してよい。

## 2. 世界観とストーリー（オリジナルの架空設定）
会津若松の静かな住宅地。小さな工房から、毎朝パンの焼ける香りが広がります。夫婦で営む「麦と日々」では、国産小麦と自家製天然酵母を使い、素材と発酵の時間に向き合いながら、一つひとつ焼き上げています。飾らない日常の食卓に、毎日食べたいパンを届けます。

店主は製パン経験12年。都内のベーカリーで経験を積み、家族と会津へ移住。仕込み・成形・焼成を夫が担当し、接客と季節商品の企画を妻が担当。※すべて創作上の人物設定。人物写真は必須にしない。

## 4. 焼き上がり・営業日機能
### 4.1 今日の焼き上がり（デモ専用）
| 時間 | 商品 | 表示 |
|---|---|---|
| 08:00 | カンパーニュ・クロワッサン | 焼き上がり予定 |
| 09:30 | あんバター・スコーン | 焼き上がり予定 |
| 11:00 | 焼きカレーパン・フォカッチャ | 焼き上がり予定 |
| 13:00 | 季節のデニッシュ | 焼き上がり予定 |

- セクション上部に**「掲載時間は架空のサンプルです。リアルタイムの在庫・焼成情報ではありません」**と記載。
- 現在時刻との照合で「焼けました」「残りわずか」「売切れ」などを自動表示しない。実際の在庫がないため。
- データは `src/data/bakery.ts` 等に集約し、非エンジニアでも修正しやすい構造にする。

### 4.2 営業カレンダー
- 月・火を定休日とした月間カレンダー、月移動可能。祝日・臨時休業は架空設定のため自動推測しない。
- ユーザーのローカルタイムで日付表示、日曜始まりか月曜始まりかを全画面で統一。
- 各日：通常営業／定休日／臨時休業（サンプル）を凡例付きで表示。
- 特別休業日はデータ配列から指定する。例示する場合はサンプルと明記。
- データが未指定なら通常スケジュールだけを表示。

## 5. デザインシステム
- デザイントーン：`Rustic / Organic / Handcrafted / Quiet`。
- 背景：`#F3EBDD`、本文：`#352B22`、主アクセント：`#626C4B`、補助：`#B18D64`、明背景：`#FFFDF8`。
- 英字見出し：品のあるセリフ体、日本語見出し：軽やかな明朝、本文：可読性の高いゴシック。Webフォントの読込失敗時にも適切なフォールバック。
- 写真：朝の斜光、焼きたてのパン、木の棚、粉の質感。過度に暗くしない。
- レイアウト：フル幅Hero、写真と文章の交互配置、商品カードはデスクトップ3列・タブレット2列・スマホ1列ないし2列。
- 装飾：極細罫線、オーバルなラベル、小麦を想起させる控えめな線画（多用しない）。
- 動き：微かなフェードアップ、商品カードの穏やかなホバー。`prefers-reduced-motion` 対応。

## 6. ページ構成・ナビゲーション
1. Header：ロゴ（タイポ主体）、`こだわり` `パン` `焼き上がり` `営業日` `店舗案内`。スマホは操作可能なメニュー。
2. Hero：大きなパン写真、主コピー、CTA、開店時間の短い補足。
3. Story：店の紹介と工房写真。
4. Commitment：3つのこだわり。
5. Menu：写真付き商品一覧とカテゴリフィルター。商品名・税込価格・説明。
6. Today：焼き上がり時間表（デモサンプル）。
7. Calendar：月間営業カレンダー。
8. Shop information：営業時間、休業日、駐車場3台、テイクアウト専門。**詳細住所・電話・地図・SNSリンクは実在しないため掲載しない**。
9. Footer：デモ注記、サイト内リンク、著作権を誤認させない表現。

## 7. 写真素材の要件
- 使用する画像は自前の生成画像、または適切なライセンスのものに限る。検索結果画像の直リンク・無断転載は禁止。
- 必要な素材と推奨比率：
  - `hero-bakery.webp`：店内のパン棚、横長16:9
  - `bread-campagne.webp`：カンパーニュ、4:5
  - `bread-croissant.webp`：クロワッサン、4:5
  - `bread-anbutter.webp`：あんバター、4:5
  - `bread-danish.webp`：季節デニッシュ、4:5
  - `bakery-process.webp`：パン作りの手元、3:2
  - `shop-exterior.webp`：郊外の小規模ベーカリー外観、3:2
- 実在店舗との混同を避けるため、架空のロゴ・看板表現のみ。
- 画像が不足してもレイアウトが崩れないプレースホルダーを設計する。

## 8. 技術・品質要件
- 推奨：Next.js App Router + TypeScript + Tailwind CSS。既存リポジトリの構成がある場合は踏襲。
- 商品、営業日、焼き上がりデータをコンポーネントから分離。バックエンドやCMSは不要。
- 商品フィルターとカレンダーはキーボード操作、フォーカス表示、アクセシブルなラベルを実装。
- セマンティックHTML、見出し階層、画像alt、コントラストWCAG AA、遅延読み込み、画像サイズ最適化。
- SEO：`title`、`description`、OG画像、適切なcanonical。**架空住所や営業時間を実在店舗のLocalBusiness構造化データとして登録しない**。デモサイトは必要に応じて `noindex`。
- 予約・購入・問い合わせ送信、決済、電話発信、SNS遷移は実装しない。
- モバイル幅320pxから確認。Lighthouseの指標を考慮し、CLSを避ける。
- バックエンド不要の静的ホスティングを想定。
