# 喫茶 ソーダ日和｜Claude Code 制作仕様書

- 文書版：v1.0 / 2026-10-13
- 種別：架空店舗の営業用ポートフォリオ・非公式デモ
- 方向性：レトロポップな喫茶店。KITO COFFEEとは色・構図・客層・動きが明確に違うサイト。

## 0. Claude Codeへの依頼

あなたはWebデザイナー兼フロントエンドエンジニアです。本書に従って **「喫茶 ソーダ日和」** の日本語Webサイトを制作してください。既存環境を尊重し、新規なら Next.js App Router + TypeScript + Tailwind CSS を推奨。淡いパステルだけの一般的なカフェサイトではなく、**昭和喫茶の記憶×現代的なポップカルチャー**を感じる独自性のあるビジュアルにしてください。店名・設定・メニュー・値段は本書から変更しないでください。

## 4. 掲載文章

### HERO
見出し：**今日も、ちょっとごきげん。**

色とりどりのクリームソーダ、ちょっぴり固めのプリン、喫茶店のナポリタン。ここは、いつもの一日を少しだけ楽しくする、小さな喫茶店。

ボタン：「メニューを見る」→ `#menu`／「お店について」→ `#about`

### ABOUT
見出し：**懐かしいのに、なんだか新しい。**

レトロなグラス、赤いさくらんぼ、ゆったりと流れる午後。ソーダ日和は、昔ながらの喫茶店のおいしさと、ときめきを詰め込んだ場所です。ひとりでも、友だちとでも、思い思いの時間をお楽しみください。

### SIGNATURE
見出し：**色で選ぶ？ 気分で選ぶ？**

メロン、いちご、青空、ゆうやけ。お気に入りの色を見つけたら、今日はきっとソーダ日和。

### PUDDING
見出し：**プリンは、ちょっぴり固めがいい。**

スプーンを入れると、むっちりとした食感。ほろ苦いカラメルと、優しい卵の風味。懐かしい味を、ゆっくりどうぞ。

### FOOD
見出し：**おなかがすいたら、喫茶ごはん。**

鉄板ナポリタンにオムライス、厚焼きたまごサンド。見た目も味も、あの頃のわくわくを。

### INFORMATION
見出し：**また来たくなる、いつもの場所。**

気の向くままに立ち寄って、ちょっとひと休み。週末の街歩きにも、ふだんの午後にも。

## 6. デザインシステム

- キーワード：Retro Pop / Nostalgic / Cheerful / Playful / Editorial
- 背景クリーム `#FFF8E9`
- ミント `#BFE9D6`
- いちごピンク `#F6AFC0`
- ソーダブルー `#8CD2E8`
- オレンジ `#F7BA73`
- ダークブラウン `#473B39`
- レイアウト：ステッカー風シェイプ、レトロ広告のような見出し、非対称の写真コラージュ。ただしカードやボタンの整列は厳密。
- タイトル：丸みのある日本語太字＋セリフ体の英字アクセント。実装時は利用規約の明確なWebフォントを使う。
- ナビ：スクロールで色が変わることは可。ただしコントラストと可読性は常時確保。
- 背景アニメーション：気泡がゆっくり上がる控えめな表現。`prefers-reduced-motion`を遵守。
- スクロール演出は見た目の補助。読み込みの遅さ・視認性低下を生まない。
- モバイルでは色面が重なりすぎないようにし、タップ領域44pxを目安とする。

## 8. インタラクション仕様

### クリームソーダ・カラーセレクター
- 5つの色名をラベル付きのラジオ形式で提示。
- 選択すると写真、メニュー名、紹介文、価格、背景アクセントが更新される。
- 初期値「メロンクリームソーダ」。
- 色だけに意味を依存させない。スクリーンリーダーにも名前と状態が伝わる。
- 実際の注文機能ではないと明記。購入ボタンは作らない。

### メニュータブ
- クリームソーダ／スイーツ／フード／ドリンクを切替。
- `role="tablist"`, `role="tab"`, 適切な選択状態とキーボード操作を実装。
- 商品カードは静的なローカルデータを読み込む。
- 価格は税込表示。架空であるとメニュー付近でも示す。

### お知らせ
- 3件の架空のサンプルニュースを表示（架空のため実施中／本日限定などの断定はしない）。
- 見出し例：`春のおすすめソーダ（サンプル）`、`季節のケーキ便り（サンプル）`、`営業日のご案内（サンプル）`。
- サイト公開日・現在日に応じた自動更新は不要。CMS連携も不要。

## 9. SEO・品質・安全なデモ公開

- `<html lang="ja">`、H1は1つ。適切なTitleとDescription（架空店舗であると分かる）。
- レスポンシブ320px〜、画像最適化、LCP/CLS配慮。
- すべての操作はキーボードから可能。フォーカス表示がある。
- WCAG AA相当の色コントラストに留意。パステル背景上には濃色文字を使う。
- `prefers-reduced-motion` が有効なら背景の泡を停止する。
- SNSアカウント・電話・住所・レビュー・Googleマップピン・実予約導線を捏造しない。
- フッターに常時表示：`このサイトはWeb制作ポートフォリオ用の架空店舗デモです。実在の店舗ではありません。`
- 外部サービスへのフォーム送信はなし。SEO用の実在ビジネスとしての構造化データを設定しない。
- フォント・画像・アイコンの権利を明確に。

## 10. テストと完成条件

- メニュー名／税込価格が本書と一致。
- 5色切替で表示内容と強調色が連動し、操作が支障なく動く。
- モバイルで文字が切れず、横スクロールが生じない。
- 視覚表現が KITO COFFEE と明確に異なる。
- すべての画像に適切なalt、すべてのUIにフォーカススタイル。
- 型検査・lint・production buildを実行して通過。
- 利用者を実在店に誘導する誤解のあるリンクや文言がない。
