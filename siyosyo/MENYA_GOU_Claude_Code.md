## 0. Claude Codeへの依頼

あなたはWebデザイナー兼フロントエンドエンジニアです。本書に従って **「横浜家系 麺屋 豪」** の日本語Webサイトを制作してください。最初にプロジェクト構造を把握し、既存環境があれば尊重します。新規の場合は Next.js（App Router）+ TypeScript + Tailwind CSS を採用してください。高級和食店ではなく、勢いのある家系ラーメン店にふさわしい、力強いタイポグラフィと視認性の高いレイアウトを実装してください。**文言・メニュー・税込価格は本書の値を使い、推測で追加しないでください。**

## 2. ブランド・商品コンセプト

- コピー：**「濃厚、一直線。」**
- サブコピー：**「炊き出した旨みを、まっすぐ一杯に。」**
- 店の価値：豚骨醤油の力強さ、中太ストレート麺、鶏油の香り、卓上調味料による味の変化。
- ターゲット：10〜40代のラーメン好き、学生、仕事帰りの会社員、がっつり食べたい家族・グループ。
- 想定の差別化：濃厚でありながら、麺の硬さ／味の濃さ／油の量を選べる。ごはんとの相性を強調。
- 避ける表現：「日本一」「元祖」「完全無添加」「地域No.1」など根拠のない優良誤認につながる文言。

### 店主ストーリー（完全な架空設定）

店主は首都圏のラーメン店で修業後、会津若松で独立。麺とスープのバランスを試行錯誤し、2024年に開業。仕込みでは豚骨と鶏ガラをじっくり炊き、醤油ダレと鶏油を合わせる。「一杯を食べ終えた瞬間に、また食べたくなる味」が目標。

## 4. 掲載用コピー（そのまま使う）

### HERO
**濃厚、一直線。**

炊き出した旨みを、まっすぐ一杯に。豚骨醤油の力強さと鶏油の香り。今日も、熱々の一杯をご用意しています。

CTA1：「お品書きを見る」→ `#menu`
CTA2：「営業案内」→ `#information`

### ABOUT
見出し：**一杯に、迷いなし。**

豚骨と鶏ガラを炊き上げたスープに、醤油ダレの輪郭と鶏油の香り。もちっとした中太ストレート麺に絡めて、最後の一口まで力強く。麺屋 豪の一杯は、濃厚な家系ラーメンの魅力をまっすぐに届けます。

### CUSTOM
見出し：**あなたの「いつもの味」に。**

麺の硬さ、味の濃さ、油の量。好きな組み合わせを選んで、自分だけの一杯を見つけてください。

### RICE
見出し：**このスープには、ごはんが合う。**

海苔をスープに浸して、ごはんをひと口。ラーメンと一緒に楽しむ、家系ならではのおいしさを。

### INFO
見出し：**腹が減ったら、豪へ。**

昼も夜も、食べたいときに。営業時間を確認してお越しください。

## 5. 情報設計・ページ

構成は1ページを基本とする。`/` に次の順で配置：
1. ヘッダー（ロゴ、Menu、こだわり、お好み、営業案内）
2. Hero（迫力ある丼写真、コピー、2CTA）
3. こだわり（スープ・麺・鶏油の3要素）
4. メニュー（ラーメン／ごはん／トッピングをタブで切替、価格は税込明記）
5. お好みシミュレーター（選択状態から注文内容のプレビュー、コピー可能）
6. 食べ方紹介（海苔×ライス、卓上調味料の活用）
7. 店舗案内（架空の営業時間、定休日、席数、駐車場台数）
8. フッター（デモ表記、住所・電話・予約リンクなし）

メニューの値段はすべて上記の架空設定を採用。注文・会計・決済につながる誤解を与えないUIにする。

## 6. デザインシステム

- ブランドキーワード：Bold / Energetic / Delicious / Authentic
- カラー：墨黒 `#151412`、深紅 `#AF2424`、白 `#FAF7F0`、黄味 `#D6A650`、補助グレー `#66615C`
- 日本語フォント：可読性の高い太字ゴシック（例：Noto Sans JP）。ライセンスと読み込み負荷に配慮。
- 英字：極太サンセリフ（例：Antonに相当するオープンライセンスフォント）
- PC：ヒーローは写真比率高め。大胆な縦方向構成、太い境界線、強い見出し。
- モバイル：メニュー・営業時間への移動を主役にする。装飾を減らし判読性優先。
- 微細演出：湯気風のゆるいCSSアニメーションは可。`prefers-reduced-motion`に対応。
- アニメーションは味覚訴求の補助であり、複雑すぎるスクロールジャック禁止。

## 7. 写真・アセット指示

必要素材：
- `hero-ramen.webp`：海苔・ほうれん草・チャーシュー・鶏油を確認できる家系ラーメン、湯気と立体感、横位置
- `soup-detail.webp`：豚骨醤油スープの質感、接写
- `noodle-lift.webp`：箸で持ち上げた中太麺
- `rice-pairing.webp`：ライス＋海苔＋ラーメン
- `shop-interior.webp`：清潔なカウンター席、実在の看板や人物識別情報なし

これらは**画像生成または正当にライセンスを取得した素材**とし、著作権・商標・肖像権を確認する。画像未準備でもグラデーションと抽象的なシェイプで成立するフォールバックを用意。実在店の料理写真を無断転載しない。

## 8. 動作仕様

- ナビゲーションはアンカー移動。現在セクションの状態が分かる。
- メニュータブはマウス・タッチ・キーボードで操作可能。切替時に表示内容が更新。
- お好みシミュレーターは3グループの単一選択。既定値は「ふつう」。選択値と「注文時の伝え方」を同時更新。
- コピーは Clipboard API に失敗した場合の手動選択代替を用意してもよい。
- 店舗情報は `src/data/store.ts`、メニューは `src/data/menu.ts` 等に切り出す。
- 外部サービスなしでも動作。バックエンド、予約、在庫連携、実際の注文機能は不要。
- JavaScript無効でも基本情報とメニューが読めるようにSSRで描画。

## 9. SEO・品質・公開方針

- `<html lang="ja">`、適切なH1は1つ、見出し階層を正しく。
- モバイル幅320px以上対応。画像は適切なaltと遅延読み込み、CLS対策。
- 文字・背景はWCAG AA相当のコントラストを確保。
- Open Graph画像は架空ブランド用に生成、タイトル例 `横浜家系 麺屋 豪｜デモサイト`。
- 店舗の構造化データ `Restaurant` を **実在店舗として公開しない**。架空のBusinessプロフィールを外部地図・口コミサイトへ登録しない。
- 本文冒頭またはフッターに常時見える注意書き：`このサイトはWeb制作ポートフォリオ用の架空店舗デモです。実在の店舗ではありません。`
- 実際の問い合わせフォーム、電話リンク、地図ルート、予約ボタンなし。
- 受け入れ条件：メニュー金額一致、スマホ操作可能、好み選択の更新、キーボード操作、ビルド成功、リンク切れなし、架空表記。
