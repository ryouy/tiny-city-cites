# 麦と日々（MUGI TO HIBI）

ベーカリー「麦と日々」のWeb制作ポートフォリオ用サイトです(架空店舗。実際の店舗・販売・予約は行っていません。この旨はフッターに1行だけ記載しています)。仕様は `../siyosyo/MUGI_TO_HIBI_Claude_Code.md` に基づきます。

> 技術構成の判断: 仕様書の標準は Next.js + Tailwind CSS ですが、本ワークスペースの既存サイト(kito-coffee / komeya 等)に揃え、Astro + TypeScript + 素のCSS の静的サイトで構築しています。

## 開発

Node.js 22.12 以上が必要です。

```sh
npm install
npm run dev       # 開発サーバー (http://localhost:4321)
npm run build     # 静的サイトを dist/ に出力
npm run preview   # ビルド結果を確認 (例: npm run preview -- --port 4404)
npm run check     # 型チェック (astro check)
npm run lint      # ESLint
npm run verify    # 仕様書とビルド結果(dist の全3ページ)の商品・価格・営業情報・禁止事項を突き合わせ(要 build)
```

## ページ構成

| URL | 内容 |
|---|---|
| `/` | トップ。写真、営業時間・定休日、今日の焼き上がり、お知らせ、おすすめのパン3点、他ページへの導線 |
| `/breads/` | パン一覧(8商品)。カテゴリ絞り込みと詳細モーダル。写真のある4商品を先頭に4列(タブレット2列・スマホ1列)で並べ、写真の無い商品は文字だけの行で続けて表示 |
| `/shop/` | お店のこと(紹介・材料と作り方)、営業カレンダー、店舗案内、地図 |

ページは `src/pages/`(`index.astro` / `breads.astro` / `shop.astro`)。共通のヘッダー・フッター・`<head>` は `src/layouts/BaseLayout.astro` に集約し、各ページから `current`(現在ページ)を渡すと `aria-current="page"` が付きます。内部リンクは `src/data/site.ts` の `href()` で `BASE_URL` 基準に生成します。

## データ編集

- `src/data/site.ts` 店舗情報・ページごとの title/description・ナビ・本文・お知らせ・店舗案内・免責文
- `src/data/menu.ts` メニュー(価格は税込の数値)。`photo` を指定した商品のみ写真枠、未指定は文字だけの行。`tags` に「人気」を入れた写真付き商品がトップの「おすすめ」に出ます
- `src/data/bakery.ts` 焼き上がり時間表、定休曜日、臨時休業の日付配列
- `src/data/photos.ts` 写真の定義(ファイル名の拡張子なし・alt・object-position・サイズ)
- `src/styles/global.css` 全スタイル(配色は先頭の CSS 変数)

焼き上がり表は固定値で、現在時刻との照合や在庫表示は行いません。臨時休業は `specialClosures` に `YYYY-MM-DD` で追加します(空配列なら通常の定休日のみ)。臨時休業の日付は過ぎたら更新してください。

## 画像の差し替え

`public/images/mugi-to-hibi/` に下記のファイル名で置くと、ビルド時に自動で実画像へ切り替わります。拡張子は webp / png / jpg / jpeg / avif を自動判定します。無い箇所は単色面に小さく「画像準備中」を表示します。配置済みの7枚は実画像です(コード変更不要。置いたあと再ビルド)。

| ファイル | 内容 | 比率 / 推奨サイズ(webp) |
|---|---|---|
| `hero-bakery.webp` | 店内のパン棚(朝の斜光) | 16:9 / 2400×1350 |
| `bread-campagne.webp` | カンパーニュ | 4:5 / 1600×2000 |
| `bread-croissant.webp` | クロワッサン | 4:5 / 1600×2000 |
| `bread-anbutter.webp` | あんバター | 4:5 / 1600×2000 |
| `bread-danish.webp` | 季節デニッシュ | 4:5 / 1600×2000 |
| `bakery-process.webp` | パン作りの手元 | 3:2 / 1800×1200 |
| `shop-exterior.webp` | 郊外の小規模ベーカリー外観(実在の看板・ロゴは入れない) | 3:2 / 1800×1200 |

WebP・1枚300KB前後が目安です。画像は自前の生成画像または利用許諾を確認したものだけを使い、検索結果画像の転載は行わないでください。実在店舗と混同される看板・ロゴは入れないこと。画像ライセンス情報はここに追記してください。

## メインサイトへの同居ビルド

```sh
BASE_PATH=/demos/mugi-to-hibi/ npm run build
```

`favicon.svg`・画像・OG画像は `import.meta.env.BASE_URL` 経由で参照するため、サブパス配下でも解決します。

## 公開上の注意

- `noindex, nofollow` と `robots.txt`(Disallow: /)を設定しています。canonical や LocalBusiness 等の構造化データは、架空店舗を実在登録しないために設定していません。
- 住所・電話・SNS・予約/問い合わせフォームは置いていません。地図は会津若松市周辺を示す埋め込み1点のみで、住所は載せていません。
- Webフォントは Google Fonts(Zen Kaku Gothic New)1ファミリーのみ。失敗時はシステムのゴシックにフォールバックします。
- OG画像(`public/og-image.png`)は店名・一行の説明とヒーロー写真で作った1200×630の画像です。

## 文体とデザインの方針

- 文章は事実(材料・価格・営業情報)だけを短い です・ます調で書く。キャッチコピー、情緒語、英語のサブコピーは置かない。商品説明は「何でできているか」の1文。
- 配色は、紙色・砂色の地に、焼き色(金茶)・濃い茶・濃い緑の色面を重ねる。トップは「写真のヒーロー → 金茶の営業情報帯 → 濃い茶の焼き上がり表 → 砂色のおすすめ → 濃い緑の導線」、パン一覧は「濃い緑の見出し帯 → 写真カード(下端に金茶の線) → 黒板風の価格表(写真のない4商品)」、お店のこと・営業カレンダー・店舗案内も色面で区切る。
- 見出し・価格・時刻は太い字(900)で大きく、補助文は小さく軽くして強弱をつける。フォントは1ファミリーのみで、明朝・イタリック・字間の広い見出しは使わない。
- 動きはホバー時の浮き上がり・写真の拡大・リンクのずれだけ(`prefers-reduced-motion` で無効)。グラデーションは、ヒーロー写真の上の文字を読みやすくする暗い膜だけに使う。ネオン・グロー・絵文字・番号飾り・英字ラベル・3列カードの繰り返しは使わない。
- 色の組み合わせは計算済み(金茶/濃い茶 7.5、紙/濃い緑 9.5、金茶/濃い緑 4.6(大きな見出しのみ)、補助文/砂色 5.6 など、本文は AA 以上)。
- 仕様書の一部の文言(ヒーロー見出し・紹介文・商品説明など)は、ポエム調のため平易な文に書き換えています。`npm run verify` は書き換え後の文言で検査します。
