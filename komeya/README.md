# お食事処 こめや デモサイト

架空の定食屋「お食事処 こめや」のポートフォリオ用サイトです。実在する店舗・商品・サービスではありません(免責はフッターに1行)。

- 技術: Astro 7 + TypeScript + 素のCSS(静的サイト / Node 22)
- 仕様書は Next.js + Tailwind が「新規の場合」の標準ですが、同一ワークスペースの既存サイト(tiny-city-cites)が Astro 静的構成のため、それに揃えました。

## 開発・起動・ビルド

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # dist/ に静的ファイルを生成
npm run preview    # ビルド結果の確認 (--port 4402 など指定可)
npm run check      # 型チェック (astro check)
npm run lint       # ESLint
npm run verify     # 仕様書のメニュー表と dist/index.html の品名・価格を突き合わせ(要 build)
```

`npm run verify` は既定で `../siyosyo/KOMEYA_Claude_Code.md` を読みます。別の場所は引数で指定してください。

## ページ構成(1ページ・実用優先)

上から順に、次のセクションです(`src/pages/index.astro`)。

1. ヒーロー: のれんの実写を全幅で先頭に置き、その下に店名・キャッチ・昼夜の営業時間・日曜休
2. お品書き: カテゴリへのスティッキーなタブ(定食 / 丼もの・ごはん / 単品 / お持ち帰り)。税込・セット条件・大盛りを上部に表示
3. 名物料理: 唐揚げ定食と会津ソースカツ丼(スマホでは写真左・文章右の2行)
4. こめやについて: ごはん・店内の写真2枚を並べ、仕様書の「About」「ごはん」「家族」の3本を集約
5. お持ち帰り: 弁当と価格
6. 店舗案内: 営業時間・L.O.・席数・駐車場・支払い・予約の案内・地図

## メニュー・店舗情報の編集

画面はすべてデータ配列から生成されます。

- `src/data/menu.ts` : お品書き(カテゴリ・品名・説明・税込価格)、お持ち帰り、看板2品。価格は数値(例: `980`)で書くと `¥980` と表示されます。
- `src/data/site.ts` : 店名、営業時間・L.O.、定休日、席数、決済、キャッチコピー、各セクション本文、免責文。
- `src/data/photos.ts` : 各写真のファイル名(拡張子なし)・alt・画像サイズ。

## 画像の差し替え

`public/images/komeya/` に次のファイル名で置くと、ビルド時に自動で拡張子(webp / png / jpg / jpeg)を判定して表示します(コード変更不要)。未配置の写真は小さな単色の「画像準備中」枠になります。

| ファイル名 | 内容 | 使用箇所 |
|---|---|---|
| `noren` | のれん・外観(16:9, 1672×941) | ヒーロー |
| `hero-karaage` | 唐揚げ定食 | 名物料理 |
| `sauce-katsudon` | 会津ソースカツ丼 | 名物料理 |
| `rice` | 炊きたてごはん | こめやについて(店内の隣) |
| `ginger-pork` | 生姜焼き定食 | お持ち帰り |
| `interior` | 店内 | こめやについて |

推奨: WebP(PNGは1枚2〜3MBあるため、公開前に圧縮を推奨)、横長4:3(1448×1086px)。写真はすべて利用許諾のあるものだけを使ってください。サイズを変える場合は `src/data/photos.ts` の `width` / `height` も合わせます(レイアウトずれ防止)。

OGP画像は `public/og.png`(1200×630)。差し替える場合は同名で置いてください。

## 公開パス(BASE_PATH)

サイト内のリンク・画像は `import.meta.env.BASE_URL` 基準です。サブパスに置く場合は `BASE_PATH=/demos/komeya/ npm run build` のようにビルドします(未指定は `/`)。

## 公開時の注意

- 検索に載せない設定です: `<meta name="robots" content="noindex,nofollow">`、`/robots.txt` は `Disallow: /`。公開しても検索エンジンに登録されないようにしています。
- canonical、LocalBusiness 構造化データ、sitemap は意図的に設定していません。
- OGP画像のURLは相対パス(`/og.png`)です。SNSでのプレビューが必要な場合は、公開URLに合わせて絶対URLへ変更してください。
- 電話番号・住所・SNS・注文/予約ボタンは置いていません。地図は会津若松市周辺(鶴ヶ城付近)の埋め込み1点のみで、住所は載せていません。
